# Support

## Getting help

- For a reproducible defect, open a Bug report.
- For a proposed improvement, open a Feature request.
- For setup questions, include your Python version, operating system, command, and the complete error message with secrets removed.

Check the README and existing issues before opening a new report.

## Safety and limitations

Do not include API keys, private datasets, passwords, or personal information in public issues. Predictions from this educational classifier are not a substitute for independent fact-checking.

For security issues, follow SECURITY.md. Support is provided on a best-effort basis.
